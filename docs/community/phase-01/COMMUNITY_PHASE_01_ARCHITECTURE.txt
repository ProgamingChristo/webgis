- frontend/app/community/page.tsx: thin route entry point.
- frontend/app/community/loading.tsx: route loading state.
- frontend/app/community/error.tsx: route error boundary.
- frontend/src/features/community/components/community-page.tsx: Community feature composition.
- frontend/src/features/community/components/community-shell.tsx: WebGIS shell frame and status surface.
- frontend/src/features/community/components/community-navigation.tsx: Phase 1 navigation scaffold with future tabs disabled.
- frontend/src/features/community/components/community-empty-state.tsx: real empty state, no fake feed.
- frontend/src/features/community/components/community.module.css: feature-owned visual styling.
- backend/app/api/community/feed/route.ts: thin HTTP adapter, auth/rate limit/envelope.
- backend/src/features/community/schemas/community.schema.ts: feed query and Unicode-safe content schema.
- backend/src/features/community/services/community.service.ts: validation and read use case.
- backend/src/features/community/repositories/community.repository.ts: Phase 1 empty read repository contract.
- backend/src/features/community/types/community.types.ts: feature domain/read types.

Request Flow:
HTTP GET /api/community/feed
  -> route auth/rate-limit/request_id
  -> CommunityService.listFeed
  -> communityFeedQuerySchema
  -> EmptyCommunityRepository.listFeed
  -> standard GETRA list envelope

Database:
- No table created in Phase 1.
- Existing community_activities remains raw evidence and is not reused as a social feed.
