GETRA PHASE 05 - KEYWORD + LOCATION SEARCH

- soto Jakarta Barat -> keyword soto, region jakarta-barat, 1 result.

Counts are runtime observations from 2026-08-28 and may change as canonical data changes. They are not hard-coded acceptance values.
