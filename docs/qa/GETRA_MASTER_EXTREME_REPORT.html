GETRA — Production Hardening ReportSection 6: Known Limitations & Final Verdict

14. Known Limitations (Truthful Disclosures)

Catatan Kejujuran: GETRA lebih baik karena lebih jujur, bukan karena berpura-pura memiliki lebih banyak data. Limitasi di bawah ini adalah bagian dari komitmen terhadap kebenaran data.
  1. DKI CCTV Streams: Feed bergantung pada infrastruktur publik eksternal. Status DEGRADED/OFFLINE/STALE mencerminkan konektivitas upstream yang sesungguhnya, bukan simulasi atau loop sintetis.
  2. GTFS-RT Vehicle Delays: Jika telematics operator transit delay, sistem menampilkan DATA_UNAVAILABLE, bukan posisi ekstrapolasi buatan.
  3. Sea Level Rise: Model 0.5m–2.0m adalah skenario risiko saintifik berbasis topografi NCICD. Di-disclaimer SCENARIO / NOT FORECAST secara eksplisit di UI dan di API response.
  4. AI Routing API Requires Auth: /api/ai/ask dan /api/routing memerlukan sesi autentikasi valid (HTTP 401 untuk unauthenticated request) — sesuai desain keamanan, bukan bug.
  5. NDVI Acquisition Lag: Data Sentinel-2 tersedia dengan keterlambatan 2–5 hari dari observasi satelit. Tanggal akuisisi selalu ditampilkan kepada pengguna.

15. Routing Architecture & Active Journey

  • Engine: Valhalla 3.8.3 — local OSM tile graph, pedestrian + multimodal costing profiles
  • Active Journey Pipeline: Select POI → Valhalla turn-by-turn → GPS snap to segment → Reroute if cross-track > 25m → Arrival at <15m threshold
  • Prohibition: Haversine dilarang sebagai routing authority. Hanya diizinkan sebagai filter bounding awal.
  • Internal Bridge: Backend container mengakses Valhalla via Docker internal network (tidak exposed ke publik)
