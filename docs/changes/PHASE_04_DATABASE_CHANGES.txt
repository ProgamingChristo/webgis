TABLE

- public.study_areas
- public.transport_corridors
- public.transport_nodes
- public.umkm_profiles

COLUMN

1. public.spatial_sources
   id uuid PK; source_name text; source_type text; description text nullable;
   metadata jsonb object; created_at timestamptz; updated_at timestamptz.

2. public.study_areas
   id uuid PK; source_id uuid nullable; name text; description text nullable;
   geometry geometry(MultiPolygon,4326); created_at/updated_at timestamptz.

3. public.transport_corridors
   id uuid PK; source_id uuid nullable; name text; transport_mode text;
   description text nullable; geometry geometry(MultiLineString,4326);
   created_at/updated_at timestamptz.

4. public.transport_nodes
   id uuid PK; source_id uuid nullable; corridor_id uuid nullable; name text;
   node_type text; transport_mode text; geometry geometry(Point,4326);
   created_at/updated_at timestamptz.

5. public.umkm_profiles
   id uuid PK; owner_id uuid; source_id uuid nullable; business_name text;
   category text; description/address text nullable; geometry geometry(Point,4326);
   created_at/updated_at timestamptz.

RELATIONSHIP / FOREIGN KEY
- study_areas.source_id -> spatial_sources.id ON DELETE SET NULL.
- transport_corridors.source_id -> spatial_sources.id ON DELETE SET NULL.
- transport_nodes.source_id -> spatial_sources.id ON DELETE SET NULL.
- transport_nodes.corridor_id -> transport_corridors.id ON DELETE SET NULL.
- umkm_profiles.source_id -> spatial_sources.id ON DELETE SET NULL.
- umkm_profiles.owner_id -> profiles.id ON DELETE RESTRICT.

GEOMETRY, CRS, DAN CONSTRAINT
- Storage CRS konsisten EPSG:4326.
- Geometry NOT NULL dan dikunci oleh typmod sesuai tipe tabel.
- is_valid_wgs84_geometry memeriksa non-null, SRID, tipe, ST_IsValid,
  dan range longitude/latitude.
- Nama/kategori/mode/type wajib non-empty.
- source_type dibatasi ke external, survey, manual, imported, system.
- metadata wajib JSON object; credential dilarang disimpan di metadata.

INDEX
- GiST: study_areas.geometry, transport_corridors.geometry,
  transport_nodes.geometry, umkm_profiles.geometry (4 index).
- B-tree: seluruh source_id yang digunakan, corridor_id, owner_id,
  transport_corridors.transport_mode, transport_nodes(transport_mode,node_type),
  umkm_profiles.category, spatial_sources.source_type (10 index).

RLS
- RLS diaktifkan pada kelima tabel Phase 4.
- anon dicabut seluruh privilege pada tabel tersebut.
- authenticated dapat membaca spatial reference data.
- hanya ADMIN dapat mengelola spatial reference data.
- owner dapat select/insert/update umkm_profiles miliknya sendiri.
- ADMIN dapat mengelola seluruh umkm_profiles.
- private.is_admin menghindari recursive profile policy; empat policy profiles
  direkonstruksi tanpa membuka data profile ke anonymous.

FUNCTION/TRIGGER
- private.is_admin(): authorization helper SECURITY DEFINER dengan search_path aman.
- public.is_valid_wgs84_geometry(): validasi type/SRID/validity/range.
- public.make_wgs84_bbox(): membuat envelope 4326 setelah validasi bounds.
- public.wgs84_distance_meters(): jarak point-to-point dalam meter via geography.
- public.handle_updated_at() dan public.handle_new_user() di-hardening.
- Lima trigger updated_at, satu untuk setiap tabel Phase 4.
