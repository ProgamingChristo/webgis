RLS STATUS:
PRESERVED / NO CHANGE. Profile dan spatial request tetap memakai Supabase client
request-scoped dengan bearer JWT. Existing profiles/spatial/UMKM RLS tetap
authorization boundary. Service-role key tidak dipakai route public.

RATE LIMIT:
- Default route dependency diubah dari no-op menjadi bounded in-memory fixed
  window enforcement.
- Auth 5, API 60, mutation 20, spatial 30 per 60000 ms default.
- Protected key berdasarkan user ID + endpoint; auth berdasarkan client identity
  hanya jika proxy trust aman.
- TRUST_PROXY=false tidak mempercayai forwarded headers.
- HTTP 429 RATE_LIMIT_EXCEEDED + Retry-After.
- Process-local/single replica; shared limiter required before horizontal scaling.

SECURITY HEADERS:
- CSP API deny-by-default.
- X-Content-Type-Options nosniff.
- Referrer-Policy no-referrer.
- Permissions-Policy disables camera/microphone/geolocation.
- X-Frame-Options DENY.
- COOP same-origin dan DNS prefetch off.
- X-Powered-By disabled.
- HSTS only when APP_ENV=production and APP_BASE_URL HTTPS.

REQUEST LIMITS:
- Global default JSON cap 65536 bytes (validated range 1024..1048576).
- Auth body 8192 bytes.
- Profile PATCH 4096 bytes.
- Spatial distance 4096 bytes.
- application/json required; streamed size check; strict UTF-8/JSON/Zod.
- Nearby result max 100 and radius cap.
- BBox default max 10 longitude degrees x 10 latitude degrees.
- Query keys/types whitelisted; duplicate/unknown keys rejected.

TIMEOUT:
- Supabase server/request clients use AbortController fetch timeout.
- Default SUPABASE_REQUEST_TIMEOUT_MS=10000; validated 1000..60000.
- API route maxDuration=15 seconds is a runtime hint, not a replacement for
  provider/database cancellation.
- MAPID timeout foundation existing; no real MAPID endpoint call.

HEALTHCHECK:
Dockerfile and Compose call GET http://127.0.0.1:3000/api/health. Probe checks
real Supabase connectivity and never returns host/user/connection credential.

READINESS:
`/api/health` is readiness (application + Supabase dependency). No separate
liveness endpoint was added. Docker detects process exit for restart, while
health state exposes dependency readiness. Unhealthy alone does not restart a
running container under plain Compose.

API VERSIONING:
Existing unversioned `/api/...` routes are preserved. New stable public domain
routes should use `/api/v1/...`; no nonexistent alias was created.
