CAMPAIGN ANALYTICS — API SPECIFICATION
================================================================================

1. GET /api/umkm/advertising/campaigns/:id/analytics
--------------------------------------------------------------------------------
Query Parameters:
- `from` (optional): ISO 8601 timestamp string (defaults to 30 days ago)
- `to` (optional): ISO 8601 timestamp string (defaults to current time)
- `placement` (optional): "SPONSORED_PIN" | "CONTEXTUAL_BANNER" | "PROFILE_POSTER"

Authorization:
- Requires authenticated user possessing verified ownership of the merchant owning the campaign.
- Cross-merchant requests return 403 Forbidden.
