UMKM ADVERTISING — PAYMENT API CONTRACT

1. POST /api/umkm/advertising/campaigns/:id/payment/checkout
--------------------------------------------------------------------------------
- Full URL: `http://localhost:3001/api/umkm/advertising/campaigns/:id/payment/checkout`
- Auth: Bearer JWT (USER with UMKM mode or ADMIN)
- Request Body: `{ "package_id"?: "string" }`
- Response:
  ```json
  {
    "success": true,
    "data": {
      "payment_order_id": "9a123...",
      "order_id": "GETRA-AD-1724490000-ABCDEF",
      "snap_token": "token-xyz...",
      "snap_redirect_url": "https://app.sandbox.midtrans.com/snap/v2/vtweb/...",
      "amount": 50000,
      "currency": "IDR",
      "status": "PENDING",
      "sandbox": true
    },
    "request_id": "req-123..."
  }
  ```

2. GET /api/umkm/advertising/campaigns/:id/payment
--------------------------------------------------------------------------------
- Full URL: `http://localhost:3001/api/umkm/advertising/campaigns/:id/payment`
- Auth: Bearer JWT
- Response:
  ```json
  {
    "success": true,
    "data": {
      "campaign_id": "camp-123...",
      "payment_order_id": "9a123...",
      "order_id": "GETRA-AD-1724490000-ABCDEF",
      "status": "PAID",
      "amount": 50000,
      "currency": "IDR",
      "provider": "MIDTRANS",
      "provider_transaction_status": "settlement",
      "paid_at": "2026-08-24T02:00:00.000Z",
      "sandbox": true
    },
    "request_id": "req-123..."
  }
  ```

3. POST /api/umkm/advertising/campaigns/:id/payment/refresh
--------------------------------------------------------------------------------
- Full URL: `http://localhost:3001/api/umkm/advertising/campaigns/:id/payment/refresh`
- Auth: Bearer JWT
- Response: Returns reconciled `PaymentStatusDTO` from Midtrans Status API.

4. POST /api/payments/midtrans/notification
--------------------------------------------------------------------------------
- Full URL: `http://localhost:3001/api/payments/midtrans/notification`
- Auth: Public Webhook with SHA-512 digital signature verification
- Request Body: Midtrans JSON notification payload
- Response: `{ "success": true, "data": { "processed": true, "order_id": "...", "status": "PAID" } }`
