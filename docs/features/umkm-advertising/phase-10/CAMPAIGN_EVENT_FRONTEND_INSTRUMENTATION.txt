GETRA - UMKM INTELLIGENCE & ADVERTISING TRACK
PHASE 10: FRONTEND INSTRUMENTATION MAP
=====================================================

1. FEATURE FILES CREATED
`frontend/src/features/umkm-advertising/events/`:
- `types/campaign-event.types.ts`: TypeScript contracts.
- `services/campaign-event.service.ts`: Safe event recorder communicating with `/api/advertising/events`.
- `utils/event-dedup.ts`: Ephemeral session key and in-memory dedup cache.
- `hooks/use-ad-impression.ts`: Reusable `IntersectionObserver` hook for DOM placements.
- `hooks/use-map-ad-impression.ts`: MapLibre viewport bounds observer hook.
- `hooks/use-campaign-event.ts`: Action dispatchers for click, profile open, and route request.

3. NON-BLOCKING ERROR RESILIENCE
All analytics calls are wrapped in non-blocking try-catch handlers. If the event endpoint encounters a network error, timeout, or rate-limit throttle, the error is caught silently, allowing the commuter's profile navigation and route calculations to proceed without friction.
