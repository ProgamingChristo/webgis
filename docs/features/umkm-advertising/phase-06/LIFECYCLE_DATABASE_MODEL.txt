2. DDL SPECIFICATION
--------------------------------------------------------------------------------
```sql
-- Phase 6: Campaign Schedule, Lifecycle & Activation Rules Migration

ALTER TABLE public.ad_campaigns
  ADD COLUMN IF NOT EXISTS start_at timestamp with time zone,
  ADD COLUMN IF NOT EXISTS end_at timestamp with time zone;

ALTER TABLE public.ad_campaigns
  DROP CONSTRAINT IF EXISTS ad_campaigns_status_check;

ALTER TABLE public.ad_campaigns
  ADD CONSTRAINT ad_campaigns_status_check
  CHECK (status IN ('DRAFT', 'READY', 'SCHEDULED', 'ACTIVE', 'PAUSED', 'ENDED', 'CANCELLED'));

ALTER TABLE public.ad_campaigns
  DROP CONSTRAINT IF EXISTS ad_campaigns_schedule_check;

ALTER TABLE public.ad_campaigns
  ADD CONSTRAINT ad_campaigns_schedule_check
  CHECK (
    (start_at IS NULL AND end_at IS NULL)
    OR
    (start_at IS NOT NULL AND end_at IS NOT NULL AND end_at > start_at)
  );

CREATE INDEX IF NOT EXISTS idx_ad_campaigns_schedule ON public.ad_campaigns(start_at, end_at);
CREATE INDEX IF NOT EXISTS idx_ad_campaigns_lifecycle_status ON public.ad_campaigns(status);
```


3. INDEXES & QUERY OPTIMIZATION
--------------------------------------------------------------------------------
1. `idx_ad_campaigns_schedule`:
   Composite b-tree index on `(start_at, end_at)` enabling fast range scans
   for active campaigns matching `start_at <= :now AND end_at > :now`.
2. `idx_ad_campaigns_lifecycle_status`:
   Index on `status` supporting fast status filtering.
3. Existing `idx_ad_campaigns_merchant_id` and `idx_ad_campaigns_created_by`
   continue to accelerate ownership and RLS joins.


4. ROW-LEVEL SECURITY (RLS) POLICIES
--------------------------------------------------------------------------------
All RLS policies on `public.ad_campaigns` established in Phase 3 remain in
effect and govern new columns:
- `Merchant owners can view their campaigns`: `SELECT` allowed when `merchants.owner_id = auth.uid()`.
- `Merchant owners can create campaigns`: `INSERT` allowed with ownership check.
- `Merchant owners can update their campaigns`: `UPDATE` allowed with ownership check.
