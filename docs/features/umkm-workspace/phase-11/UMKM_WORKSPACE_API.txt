1. GET /api/umkm/workspace
--------------------------------------------------------------------------------
Summary:
Retrieves the aggregated dashboard overview for the authenticated UMKM user.

Authentication:
- Required (Bearer JWT in Authorization header)
- Stakeholder Mode: UMKM (or ADMIN account role)

Response Status:
- 200 OK (Successful overview aggregation)
- 401 Unauthorized (Missing or invalid auth token)
- 403 Forbidden (Authenticated user lacks UMKM stakeholder mode)
