8. Existing shared runtime providers
- frontend/app/layout.tsx wraps all routes with AuthProvider and StakeholderProvider.
- AuthProvider currently guards:
  - guest protected route -> `/login`
  - non-admin `/admin/*` -> `/app`
  - authenticated incomplete onboarding -> `/onboarding`
  - authenticated complete visiting `/login` or `/signup` -> `/app`

10. Phase 06 implementation notes
- Redesign should introduce reusable application design primitives rather than isolated one-off page styling.
- Do not modify public landing visual direction except if needed for regression-safe shared assets.
- Do not change account_role model.
- Do not persist GENERAL/COMMUTER as stakeholder modes.
- Do not expose admin controls to non-admin users.
