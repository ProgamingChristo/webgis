================================================================================
GETRA — GEO-ENABLED TRANSIT & RETAIL ANALYTICS
MERCHANT SUBMISSION — API SPECIFICATION
================================================================================

1. USER SUBMISSION APIS
--------------------------------------------------------------------------------
- `POST /api/umkm/merchant-submissions`
  - Creates a new submission draft.
  - Body: `{ name, category, description?, address?, location: { type: "Point", coordinates: [lng, lat] }, image_url? }`
  - Returns 201 Created with `{ submission: ..., duplicate_warning?: ... }`

- `GET /api/umkm/merchant-submissions`
  - Lists all submissions belonging to authenticated user.

- `GET /api/umkm/merchant-submissions/:id`
  - Retrieves detail of specific submission.

- `PATCH /api/umkm/merchant-submissions/:id`
  - Updates draft submission fields.

- `POST /api/umkm/merchant-submissions/:id/submit`
  - Transitions submission from `DRAFT` to `PENDING_REVIEW`.

- `POST /api/umkm/merchant-submissions/:id/cancel`
  - Cancels a pending submission.

2. ADMIN CURATION APIS
--------------------------------------------------------------------------------
- `GET /api/admin/merchant-submissions?limit=50&offset=0`
  - Lists pending submissions awaiting review.

- `POST /api/admin/merchant-submissions/:id/approve`
  - Body: `{ "note"?: "string" }`
  - Atomically creates canonical merchant, establishes verified ownership, and sets status `APPROVED`.

- `POST /api/admin/merchant-submissions/:id/reject`
  - Body: `{ "note": "string (mandatory rejection reason)" }`
  - Sets status `REJECTED` and records rejection rationale.
