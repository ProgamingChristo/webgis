Core message
------------
GETRA for UMKM is not only about appearing on a map. It supports local business context, merchant presence management, transparent commuter reach, and spatial insight.

Technical accuracy
------------------
- UMKM is a stakeholder mode.
- UMKM is not an authorization role.
- Account role remains USER or ADMIN.
- Merchant ownership is verified separately.
- Having UMKM stakeholder mode does not automatically grant merchant ownership.
