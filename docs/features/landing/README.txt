GETRA PUBLIC LANDING
====================

Purpose
-------
Public landing memperkenalkan GETRA sebagai Geo-Enabled Transit & Retail
Analytics: WebGIS spatial intelligence untuk transportasi massal, akses
pedestrian, UMKM, dan kawasan transit.

Frontend root
-------------
frontend/src/features/landing

Backend root
------------
N/A. Phase 01 bersifat frontend-only.

Public route
------------
/ adalah landing publik.

Auth relationship
-----------------
/login dan /signup tetap menjadi auth entry. Aplikasi lama yang sebelumnya
berada di / dipindahkan ke shell /app agar landing tetap publik.

Current phase
-------------
Phase 01: Foundation, Public Routing, Tailwind CSS v4 Design System &
WebGIS Hero Experience.

Future phases
-------------
Phase 02+ dapat menambahkan full Why GETRA storytelling, Fair Discovery,
Community, UMKM, Advertising, Business Space, Technology, dan animasi final.
