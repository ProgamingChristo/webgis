GETRA API ENDPOINT MATRIX
=========================

Tanggal pembaruan: 2026-08-16 (Asia/Jakarta)

CLASSIFICATION
--------------
PUBLIC           : dapat dipanggil tanpa bearer; validation/rate/CORS tetap ada.
AUTHENTICATED    : wajib Supabase bearer token valid.
ROLE_RESTRICTED  : bearer + allowed role tertentu.
ADMIN            : bearer + ADMIN server-side guard.
INTERNAL         : guard internal/admin/environment/scoped credential sesuai use.

Semua endpoint di bawah memakai exact-origin CORS policy. Request tanpa Origin
diterima untuk server-to-server/CLI, tetapi tidak melewati auth. Semua endpoint
mempunyai OPTIONS handler dengan method/header minimal sesuai path.

RATE-LIMIT PROFILES (DEFAULT)
-----------------------------
NONE      : tidak memakai application limiter (health).
AUTH      : 5 request / 60000 ms / client / endpoint.
API       : 60 request / 60000 ms / user / endpoint.
MUTATION  : 20 request / 60000 ms / user / endpoint.
SPATIAL   : 30 request / 60000 ms / user / endpoint.

Nilai dapat dikonfigurasi environment. Limiter process-local/single-instance;
lihat `docs/PUBLIC_API_SECURITY.txt` sebelum horizontal scaling.

API VERSIONING STATUS
---------------------
Endpoint existing tetap `/api/...` untuk compatibility. `/api/v1/...` adalah
strategy untuk public domain endpoint baru, bukan path yang tersedia saat ini.

STANDARD RESPONSE
-----------------
Success:

  {
    "success": true,
    "data": {},
    "request_id": "UUID"
  }

Error:

  {
    "success": false,
    "error": {
      "code": "...",
      "message": "...",
      "retryable": false
    },
    "request_id": "UUID"
  }

429 menambahkan `Retry-After`. Semua response menambahkan `X-Request-ID` dan
`Cache-Control: no-store`. Detail security header ada di PUBLIC_API_SECURITY.txt.
